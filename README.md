# AI Studio PRO

AI Studio PRO to prywatna aplikacja desktopowa służąca do obsługi własnych zamówień Allegro, komunikacji z klientami oraz organizacji procesu realizacji usług graficznych i AI.

Aplikacja korzysta z Allegro REST API w zakresie:
- odczytu zamówień,
- odczytu danych ofert,
- komunikacji w Centrum Wiadomości,
- identyfikacji połączonego konta Allegro.

Aplikacja jest wykorzystywana wyłącznie na potrzeby własnego konta Allegro.
